# Winter Experiment Identity Audit

## 1. Existing Pattern（2026-08-22 22:24 +08:00）

Summer/frozen evidence uses two existing strict contracts:

| Artifact | Existing location/pattern | Owner |
|---|---|---|
| RunContext | frozen demo `*.run-context.json`; generated by `arctic-route-context create` | shared contracts |
| ExecutionSpec | Orchestrator `examples/*.execution-spec.json` and frozen execution inputs | Orchestrator |

`RunContext.v2` binds scenario/corridor/vessel digests, exact A bundle ID/digest, simulation window
and public `config_digest`. `ExecutionSpec.v1` binds run/scenario IDs, generation/input revision,
creation time, planning contract, snap/replan/timeout parameters. Full run intake cross-checks
`run_id`、`scenario_id` 和 `generated_at/created_at`。

The task requested bundle SHA, code versions, and B/C configuration inside ExecutionSpec. Existing
schema v1 cannot contain them because `additionalProperties=false`. No schema extension was made.

| Requested metadata | Existing legal owner |
|---|---|
| bundle ID/digest | `RunContext.v2` |
| bundle file SHA-256 | experiment audit/report |
| contracts/A/B/C/Orchestrator commits | experiment setup report and final run report |
| B config | explicit Orchestrator `--b-config`; currently pending approval |
| C config | explicit `--c-config-root`; current planner unchanged |

This preserves the frozen interfaces and prevents Winter-only field drift.
