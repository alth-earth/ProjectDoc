# Archive: Deprecated

This category holds documentation explicitly marked **deprecated** (replaced by a
superseding canonical doc and no longer referenced as current).

**Current state (2026-08-20):** No documents are currently classified as deprecated.
Deprecated material from the pre-governance era was either merged into the canonical
`current/` docs, moved to `archive/superseded/`, or retained in
`archive/pre-governance/`. If a doc is later marked deprecated, it should be placed
here with a clear supersession reference.
